Since our products operate in environments reaching **95% relative humidity**, reliability is a key design consideration. I prefer hardware architectures that allow quick field replacement through modular connections using **JST connectors**.

## 📡 Communication Architecture

### Version 1 – I²C

Initially, I used **I²C communication** because it provided a simple and efficient way to connect multiple sensors and peripherals.

### Version 2 – RS485

As the system evolved and cable lengths increased, communication became more susceptible to electrical noise.

To improve reliability, I migrated to **RS485 communication**, which offers:

- Better noise immunity
- Long-distance communication capability
- Improved robustness in industrial environments
- More reliable data transmission between distributed nodes

This transition significantly improved communication stability in real-world deployments.
